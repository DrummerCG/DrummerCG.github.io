Cómo construí este CV

Decisiones técnicas, arquitectura y lecciones aprendidas

Tecnologías utilizadas

Core — sin frameworks

El portafolio está construido en HTML5, CSS3 vanilla y JavaScript puro (ES6+), sin ningún framework ni bundler. La decisión fue intencional: demostrar dominio de los fundamentos del frontend, reducir dependencias y producir un único archivo .html autocontenido que cualquier persona puede abrir, compartir y publicar sin instalar nada.

CDNs externos

  • Font Awesome 6.5 — iconografía general
  • Devicons 2.15 — logos de tecnologías
  • Google Fonts — tipografías Syne + DM Sans

Persistencia

localStorage guarda la foto de perfil junto con su zoom y posición exacta (base64 + transform). La próxima vez que se abre el archivo en el mismo navegador, la foto restaura automáticamente el estado que tenía.

Diseño visual

Sistema de CSS Custom Properties (tokens de diseño) para paleta, sombras y radios. Tipografía dual: Syne para títulos con carácter y DM Sans para cuerpo legible. Color base #1c3c6c con acento azul y oro para jerarquía visual.

Arquitectura del archivo

Single-file SPA simulada

El archivo funciona como una Single Page Application sin router. Cada sección es un <div class="page"> con display:none por defecto. La función goTo(n) activa una página ocultando las demás con classList.toggle('active'). La navegación responde a clics en pestañas, flechas de teclado (←→) y botones prev/next. La animación de transición es un @keyframes fadeIn CSS aplicado al activarse la clase.

8 páginas 1 archivo HTML 0 dependencias locales ~1200 líneas CSS tokens localStorage

Problemas resueltos

PDF solo mostraba la página activa

El CSS ocultaba las páginas inactivas con display:none, lo que hacía que al imprimir solo apareciera la visible. Solución: interceptar los eventos beforeprint y afterprint del navegador para mostrar todas las páginas antes de imprimir y restaurar el estado posterior. El botón "Descargar CV" usa la misma lógica vía window.print().

Foto con tamaño fijo y sin persistencia

La primera versión usaba FileReader directamente sobre <img>, lo que perdía la foto al recargar y no permitía ajustar el encuadre. Se implementó un modal editor con tres sliders (zoom 50–250%, posición X/Y ±80px) y CSS transform: scale() translate() aplicado en tiempo real. Al confirmar, se serializa todo en localStorage como objeto JSON con el base64 y los valores de transformación.

Navegación desbordada en móvil

Las 8 pestañas no caben en pantallas de 360px. Solución: overflow-x:auto; flex-wrap:nowrap en el contenedor de tabs con scrollbar-width:none para ocultar la barra de scroll. En móvil el nav se apila verticalmente y las pestañas se deslizan horizontalmente con el dedo.

Colores desaparecían al imprimir

Los navegadores suprimen colores de fondo por defecto al imprimir. Solución: -webkit-print-color-adjust: exact; print-color-adjust: exact en el bloque @media print, más page-break-inside: avoid en cada tarjeta para evitar cortes en medio de bloques de contenido.

Funcionalidades implementadas

Navegación tipo libro

Pestañas, flechas de teclado y botones prev/next. Animación fade suave entre páginas. Contador de página visible.

Editor de foto con persistencia

Modal con zoom, posición X/Y. Guarda en localStorage. Restaura al reabrir el archivo en el mismo navegador.

Descarga como PDF

Botón y Ctrl+P muestran todas las páginas antes de imprimir y restauran la vista interactiva después.

Modo oscuro

Toggle en la barra de navegación. CSS Custom Properties completas. Preferencia guardada en localStorage.

Multiidioma ES / EN

JSON de traducciones integrado. Cambio instantáneo sin recarga. Idioma guardado en localStorage.

Formulario de contacto

Formulario funcional via Formspree. Sin backend ni servidor. Fallback automático a mailto si no hay ID configurado.

Animaciones Intersection Observer

Elementos animados al entrar en viewport con reveal, reveal-left, reveal-scale y stagger escalonado.

Analytics GA4 integrado

Google Analytics 4 cargado dinámicamente. Solo activo si configuras tu Measurement ID. Tracking de page views.

Exportar configuración

Botón JSON en la navbar descarga un archivo con tema, idioma, foto (base64) y ajustes actuales.
